# TravonetWG App

Android-клиент для WireGuard с userspace-обходом DPI и прямым подключением к Cloudflare WARP.

Приложение не требует root, не использует VPS и не отправляет приватные ключи на сторонние серверы. WARP-ключи генерируются прямо на телефоне, регистрация анонимная.

## Что умеет

- Импорт обычных WireGuard-конфигов (`.conf`).
- Прямое подключение к Cloudflare WARP.
- Режимы **VPN (системный TUN)** и **SOCKS5 (127.0.0.1:1080)**.
- Стратегии обхода DPI на уровне обычных UDP-сокетов: `junk`, `mimic(quic/stun)`, `fake_udp`, `sleep`.
- Готовые пресеты для мобильной сети и проводного интернета.
- Статистика трафика и состояния handshake.
- Работа без root и без CAP_NET_RAW.

## Требования

- Android 9 (API 28) или новее.
- Поддерживаемые ABI: `arm64-v8a`, `armeabi-v7a`, `x86_64`, `x86`.

## Установка

1. Откройте [Releases](https://github.com/SudoNeko68/TravonetWG-App/releases).
2. Скачайте APK:
   - `arm64-v8a` — почти все современные телефоны;
   - `armeabi-v7a` — старые 32-битные устройства;
   - `x86_64` / `x86` — эмуляторы и редкие устройства;
   - `universal` — если не уверены, какой ABI нужен.
3. Разрешите установку приложений из неизвестных источников для файлового менеджера или браузера.
4. Установите APK и откройте TravonetWG.

Если APK уже установлен, при обновлении поверх старой версии данные профилей сохраняются.

## Быстрый старт с WARP

1. Откройте вкладку WARP.
2. Нажмите регистрацию/создание профиля.
3. Выберите профиль и стратегию **«WARP / Мобильная сеть (Рекомендуемая)»**.
4. Нажмите **«Пуск»** и разрешите создание VPN-подключения.

Рекомендуемая последовательность для WARP:

```text
junk(64) -> mimic(quic) -> mimic(stun) -> junk(64)
-> fake_udp(148, corrupt=true) -> sleep(15ms) -> handshake
```

Первый `junk` важен: если поток начинается сразу с крупного QUIC-пакета, Cloudflare часто не отвечает на handshake.

## Стратегии

В приложении есть несколько готовых вариантов:

- **WARP / Мобильная сеть** — основная проверенная схема для LTE/5G и Wi-Fi.
- **WARP Lite** — меньше пакетов, без fake-handshake.
- **WARP без второго junk** — если провайдер режет повторный junk.
- **WARP Aggressive** — двойной pre-junk для сложных сетей.
- **WARP с паузами** — для DPI, который смотрит на тайминги.
- **WARP / Проводной интернет (jumbo)** — для домашнего Wi-Fi/проводного интернета.
- **WARP + IP Options** — только для проводных сетей.
- **WARP для SOCKS5** — та же схема для режима SOCKS5.
- **Чистый WireGuard** — без обхода, только штатный WireGuard.

Все стратегии работают в userspace. Сырые фрагменты IP и действия, требующие CAP_NET_RAW, в пресетах не используются.

## Сборка

Требуются JDK 17+ и Android SDK/NDK.

```bash
./gradlew assembleDebug
```

Release-сборка:

```bash
./gradlew assembleRelease
```

Готовые нативные библиотеки лежат в `app/src/main/jniLibs/`. Если вы меняете ядро TravonetWG, пересоберите `.so` для четырёх ABI и замените файлы в этой папке.

## Проверка контрольных сумм

В каждом релизе есть файл `SHA256SUMS`. Проверка на Linux/macOS:

```bash
sha256sum -c SHA256SUMS
```

На Windows удобно использовать PowerShell:

```powershell
Get-FileHash .\TravonetWG-1.2.0-1-arm64-v8a.apk -Algorithm SHA256
```

Сравните полученное значение с соответствующей строкой в `SHA256SUMS`.

## Важное замечание

Обход DPI не гарантирует работу в любой сети. Провайдеры и Cloudflare периодически меняют поведение, поэтому стратегии могут требовать подбора. Если соединение не устанавливается, попробуйте другой пресет или добавьте свой конфиг.
